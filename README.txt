WESTBRIDGE SMM — Phase 1 homepage preview

Files:
- index.html: public homepage
- assets/css/styles.css: responsive styling
- assets/js/main.js: mobile navigation and footer year

Important:
This is a frontend preview only. Login, registration, customer dashboard, wallet,
payments, order processing, provider APIs and admin functions are not connected
or active. Do not accept customer payments or orders until the backend, security,
provider compliance and payment webhooks have been implemented and tested.

To preview:
1. Extract the ZIP.
2. Open index.html in a modern browser, or serve the folder using a local web server.
3. The navigation links to login.html, register.html and services.html are planned
   pages and will be implemented in later phases.
